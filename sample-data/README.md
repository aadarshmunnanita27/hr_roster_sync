# Synthetic samples

All names and contact values in these files are synthetic; email addresses use
the reserved `.invalid` domain. The files cover valid rows, rejected rows,
duplicate IDs and an intentionally small/incomplete roster.

The CSV columns are `employeeId`, `sourceVersion`, `name`, `email`, `phone`,
`managerId`, `officeCode`, `shift`, and optional `active`. Do not add real
employee information to sample data or commit it to the repository.
